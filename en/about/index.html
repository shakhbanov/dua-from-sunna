About this project

A digital collection of duas and adhkar: 212 chapters and 409 supplications with the Arabic text, word-by-word Russian and English translation, and a source reference for every supplication.

Who maintains it

Compiled and developed by Zurab Shakhbanov. The project is non-commercial and open source: the entire text of the collection, its markup and its code are published in the GitHub repository — the edit history of every chapter can be read in full.

Sources

Every supplication carries a source reference shown on the page itself. For duas from the Sunnah and for the hadith of an-Nawawi this is the hadith collection and number (al-Bukhari, Muslim, Abu Dawud, at-Tirmidhi, Ibn Majah, an-Nasa'i, Ahmad). For Quranic supplications it is the sura and ayah number.

The primary source takes precedence over this site. Where the text, translation or reference given here disagrees with the primary source, the primary source is correct and the page is to be corrected.

Reporting an error

Reports of errors in the Arabic text, the translation, the diacritics or the source reference are accepted publicly — through the repository issues. Please give the page address and the nature of the discrepancy. Corrections are made to the chapter source file, so each one stays in the open edit history.

Dates

The publication and modification dates of every chapter are taken from the git history of its source file rather than set by hand. The update date changes only when the chapter content actually changed.
