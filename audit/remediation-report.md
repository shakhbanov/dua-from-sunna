## 5. Что сломалось в процессе

**Регресс hreflang на страницах «О проекте».** Новый маршрут `about` не имел ветки в `buildHreflangAlternates()` и проваливался в ветку главной: `/o-proekte/` объявлял своими альтернативами `/` и `/en/`. Поймано проверкой 6 при первом же прогоне, до деплоя. Исправлено добавлением ветки.

**Слабость в проверке 2, найденная после первого пуша.** Проверка сравнивала sitemap с `HEAD:public/sitemap.xml`, но сборка сама перезаписывает этот файл и он коммитится вместе с изменением — то есть sitemap сравнивался сам с собой и никогда не мог сработать. Переведена на `HEAD~1`. Подтверждено: удаление URL из сборки теперь роняет проверку. Это именно та проверка, которая поймала бы P1-01.

**Дыра в проверке 7.** Она сэмплировала по 3 страницы на группу, поэтому поломка вне выборки прошла бы мимо. Расширена на все 342 страницы глав.

## 6. Опровержения

**«240 отсутствующих OG-изображений» — ЛОЖНАЯ ТРЕВОГА.** В середине работы я замерил `dist/` до завершения сборки: лог обрывался на пререндере, генерация OG ещё шла, в каталоге лежало 135 файлов из 173. Я объявил регресс инварианта №6 и тут же его отозвал. На завершённой сборке — 0 отсутствующих.

Это ровно та ошибка, из-за которой исходный аудит выдал три ложных вывода. Правило D-01 существует потому, что ошибку легко повторить — и я её повторил. Сработала не осторожность, а перепроверка перед фиксацией.

**«Ссылки на главной» — не то, чем казались.** Аудит зафиксировал 340 исходящих ссылок с `/` как факт. Факт верен, но эти ссылки жили в `aria-hidden` блоке за пределами экрана (`left:-10000px`), написанном для краулеров. По R-03 это запрещённый приём, и чинить P1-03 надо было не восстановлением блока, а настоящей видимой навигацией. Блок удалён; 140 ссылок на каждой странице — это боковая панель, которую видит читатель.

### Как включить Enforce HTTPS

1. `github.com/shakhbanov/dua-from-sunna` → **Settings** → **Pages**
2. Внизу, под Custom domain, галка **Enforce HTTPS**
3. Если галка серая — подождать выпуск сертификата (обычно минуты), обновить страницу

Проверка: `curl -sSI http://dua.shakhbanov.org/` должен отдать `301` на `https://`.

### Как подключить Search Console

1. `search.google.com/search-console` → **Add property** → **URL prefix** → `https://dua.shakhbanov.org`
2. Метод **HTML tag** → скопировать значение `content`
3. GitHub → Settings → Secrets and variables → Actions → New secret, имя `VITE_GOOGLE_VERIFICATION_CODE`
4. Запустить деплой; `scripts/generate-verification.mjs` положит файл сам
5. Bing: `bing.com/webmasters` → Import from Google Search Console
